# 이미지 속 일본어

## 조사 결과: 이미지에 박힌 일본어는 타이틀 로고 하나뿐

먼저 "일본어가 들어간 이미지"가 어디에 얼마나 있는지부터 확인했습니다.

### 방법

정적 분석만으로는 그래픽 위치를 특정하지 못했습니다. 4bpp 타일로 렌더해 봐도
타일셋은 타일맵 없이는 조립되지 않고, 폭 자동 검출도 뚜렷한 값이 나오지 않았습니다
(세로 연속성 0.33 수준으로 평탄 — 선형 비트맵이 아니라는 뜻).

그래서 **실행 중인 화면을 그대로 가져오는** 방법을 썼습니다.

1. mGBA 의 GDB 서버에 붙어 VRAM(96KB)·팔레트·OAM·IO 레지스터를 덤프
2. `DISPCNT`·`BGnCNT` 를 해석해 BG 레이어를 실제 화면대로 재구성
3. 화면에 쓰인 타일 바이트를 **ROM 에서 역검색**해 원본 위치를 확정

키 입력은 UI 조작 없이 넣었습니다. 키 처리 루틴을 찾아

```asm
08002482: ldr  r0, [pc, #0x1c]   ; 0x04000130 (KEYINPUT)
08002484: ldrh r1, [r0]
08002486: mvns r1, r1            ; GBA 키는 active-low
08002494: bics r0, r2            ; 새로 눌린 키 = 현재 & ~직전
08002496: strh r0, [r4]          ; [0x03001478] 새로 눌림
08002498: strh r1, [r3]          ; [0x03001470] 현재
```

루틴이 끝나는 지점에 브레이크포인트를 걸고, 멈출 때마다 두 변수에 원하는 키를
써 넣어 게임을 진행시켰습니다. (`analysis/drive.py`)

### 확인한 것

주요 화면을 순회해 보니 **이 게임은 거의 모든 문자를 폰트로 그립니다.**
시나리오 선택, 다이묘 선택, 커맨드 메뉴, 인물 열전 — 전부 12×12 폰트 출력이라
이미 한글로 나옵니다.

이미지에 일본어가 통째로 그려진 곳은 **타이틀 로고 `信長の野望`** 하나였습니다.
(`Press Start Button`, `© 2001 KOEI CO.,LTD.` 는 영문이라 그대로 둡니다.)

> 초기 조사에서 `0x232000` 대가 "일본어 텍스트 그래픽"처럼 보였지만,
> 이는 **SJIS 대사 데이터를 4bpp 타일로 잘못 렌더한 착시**였습니다.
> 그 구간은 실제로는 대사 텍스트 영역입니다.

## 타이틀 로고 교체

### 원본 구조

| 항목 | 값 |
|---|---|
| 레이어 | BG0, **8bpp**(256색), 우선순위 3 |
| 타일 데이터 | VRAM `0x4000` ← ROM **`0x08002C`** (타일 0~203)<br>VRAM `0x7300` ← ROM **`0x0595F0`** (타일 204~) |
| 화면 맵 | VRAM `0xE000`, 30×20 칸 |
| 압축 | **없음** (ROM 바이트가 VRAM 과 그대로 일치) |
| 글자 색 | 크림 면 `(248,248,192)` / 빨강 외곽 `(248,0,0)` / 어두운 그림자 |
| 글자 영역 | x 17~221, y 35~93 (205×59px) |

로고는 별도 스프라이트가 아니라 **불꽃 배경 그림에 통째로 그려져** 있습니다.

### 작업

1. **글자 픽셀 검출** — 크림 계열 + 채도 높은 빨강.
   팔레트 인덱스만 보면 어두운 외곽선을 놓쳐 획이 남으므로 RGB 조건도 함께 씁니다.
2. **배경 복원** — 검출 영역을 주변 배경에서 반복 확산으로 메웁니다(60회).
   불꽃 그라데이션이라 자연스럽게 이어집니다.
3. **한글 그리기** — 원본과 같은 3겹 구조로 그립니다.
   그림자(우하 3px) → 빨강 외곽(2px) → 크림 면
4. **8bpp 인덱스화** — 원본 팔레트에서 가장 가까운 색을 찾습니다.
   팔레트와 타일맵은 건드리지 않습니다.
5. **타일 기록** — 화면 30×20 칸을 타일 단위로 되돌려 해당 ROM 오프셋에 씁니다.

### 글자 크기

원문 `信長の野望` 은 5자가 205px, **자당 약 41px** 입니다.
`노부나가의 야망` 7자를 한 줄에 넣으면 자당 29px 로 작아지므로,
**두 줄로 나눠 자당 41px 을 지켰습니다.**

```
노부나가의
   야망
```

### 공유 타일 처리

같은 타일을 여러 칸이 쓰는 경우가 37개 있었습니다.
'글자를 지운 새 내용'과 '원래 그대로'가 충돌하는데, 그냥 건너뛰면 지워야 할 획이
화면에 남습니다. 그래서 **원본과 가장 많이 다른 쪽(= 글자를 지운 결과)** 을 채택합니다.
배경 무늬는 어디서 쓰이든 같은 그림이라 이렇게 해도 안전합니다.
