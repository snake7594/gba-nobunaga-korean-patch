# 노부나가의 야망 (GBA) 한국어 패치

<p align="center">
  <img src="images/sample_korean.png" width="620" alt="한글화 렌더링 샘플">
</p>

GBA용 『信長の野望』(KOEI, 2001 / 롬 코드 `ANBJ`)의 **비공식 한국어 팬 번역 패치**입니다.
게임 텍스트 **7,138개 문자열 전체**를 한국어로 번역하고, 12×12 비트맵 폰트에 한글 글리프를 주입했습니다.

> **롬 파일은 포함되어 있지 않습니다.** 본인이 소유한 정품 롬에 xdelta 패치를 적용해 사용하세요.

---

## 1. 적용 방법

### 준비물

| 항목 | 값 |
|---|---|
| 원본 롬 | `Nobunaga no Yabou (Japan).gba` |
| 원본 MD5 | `2d1ceffbc8c34e3101ab91ea49f43a44` |
| 원본 크기 | 4,194,304 바이트 (4 MB) |
| 패치 | [`patch/Nobunaga_Korean.xdelta`](patch/Nobunaga_Korean.xdelta) |

### 패치 적용

```bash
xdelta -d -s "Nobunaga no Yabou (Japan).gba" Nobunaga_Korean.xdelta "Nobunaga no Yabou (Korean).gba"
```

GUI를 쓰신다면 [xdeltaUI](https://www.romhacking.net/utilities/598/) 에서
Source = 원본 롬, Patch = `Nobunaga_Korean.xdelta` 를 지정하면 됩니다.

### 결과 확인

| 항목 | 값 |
|---|---|
| 패치본 MD5 | `9d0fc1753c1cd3b9c6819b15aac6200f` |
| 패치본 크기 | 4,194,304 바이트 (**원본과 동일**) |

크기가 원본과 같으므로 플래시카트·에뮬레이터 어디서든 그대로 동작합니다.

## 2. 패치 내용

| 항목 | 수치 |
|---|---|
| 번역된 문자열 | **7,138개** |
| 원문 분량 | SJIS 143 KB / 고유 문자열 3,332종 |
| 주입한 한글 글리프 | **787자** (갈무리11, 12×12 픽셀) |
| 제자리 기록 / 재배치 | 5,753 / 1,354 |
| 오버플로·잘림 | **0건** |

번역 범위는 다음과 같습니다.

- 타이틀·모드 선택·난이도 등 **시스템 메뉴**
- 내정 / 군사 / 인사 / 외교 / 거래 전 **커맨드 메뉴와 도움말**
- 합전·평정·이벤트 **대사 전체** (사투리 대사 포함)
- **인물 열전** 수백 건, 시나리오 해설, 다기(茶器) 설명
- 세이브·로드·통신 대전 등 **시스템 메시지**

### 번역 방침

| 대상 | 방침 | 예 |
|---|---|---|
| 인명·지명·성(城)·구니(国) | 한자 독음 + 두음법칙 | 織田信長 → 직전신장, 龍造寺 → 용조사, 六角 → 육각 |
| 게임 용어 | 용어집 통일 | 大名 → 다이묘, 足軽 → 아시가루, 一揆 → 잇키 |
| 가나 표기 고유명사 | 외래어 표기법 음차 | ぬらりひょん → 누라리횬 |
| 가신 → 주군 대사 | 사극체 | ~하옵니다 / ~이옵니다 / ~하시오소서 |
| 나레이션·인물 열전 | 평서체 | ~했다 / ~이다 |
| 시스템 메시지 | 경어체 | ~합니다 / ~하시겠습니까? |

용어집과 독음표 전문은 [`data/glossary.json`](data/glossary.json), 원문↔번역 전체 대조는
[`data/번역대조표.txt`](data/번역대조표.txt) 에 있습니다.

## 3. 기술 구조

### 롬 내부 배치

| 항목 | 주소 | 설명 |
|---|---|---|
| 본문 폰트 12×12 | `0x305274` | 글리프당 **18바이트** (행당 12비트 패킹, MSB=왼쪽), 1,869자 |
| 문자 매핑 테이블 | `0x30D6CE` | u16 LE **SJIS 오름차순** 1,869개 |
| 렌더러(이진 탐색) | `0x08003620` | SJIS 코드 → 슬롯 인덱스 |
| ASCII 폰트 8×12 | `0x304DF4` | 96자, 12바이트/자 |
| 재배치 텍스트 영역 | `0x33A1A0` ~ `0x356788` | 원본 패딩 구간, 116 KB 사용 |

글리프 주소는 `0x305274 + slot × 18` 로 계산됩니다.
텍스트는 **평문 Shift-JIS**이며 LZ77 등 압축은 쓰이지 않습니다.

### 한글 주입 방식

이 게임은 SJIS 코드를 매핑 테이블에서 이진 탐색해 슬롯 번호를 얻고,
그 슬롯의 비트맵을 그립니다. 따라서 **매핑 테이블을 건드리지 않고**
기존 한자·가나 슬롯의 **글리프 이미지만 한글로 교체**하면
게임 코드를 전혀 수정하지 않고도 한글이 출력됩니다.

```
"한" ──▶ 슬롯 218 배정 ──▶ 0x305274 + 218×18 에 '한' 비트맵 기록
                          └─ 원래 이 슬롯의 SJIS 코드(阿, 0x88A2)를 그대로 재사용
텍스트에는 0x88A2 를 기록 ──▶ 게임이 이진 탐색 ──▶ 슬롯 218 ──▶ '한' 출력
```

- 한자 1,633 + 히라가나 71 + 가타카나 78 = **1,782 슬롯**을 한글에 사용 가능
- 실제 사용 787자 → 여유 충분
- 기호·전각 숫자·영문 69자는 원본 유지 (`、。「」（）０-９Ａ-Ｚ` 등)
- 가이지(외자) 18자는 `{G00}`~`{G17}` 토큰으로 보존

음절↔슬롯 대응 전체는 [`data/폰트슬롯표.txt`](data/폰트슬롯표.txt) 를 보세요.

### 문자열 재배치

번역문이 원래 자리에 안 들어가는 경우, 롬 끝 패딩 영역으로 옮기고
그 문자열을 가리키던 포인터를 갱신했습니다.
포인터를 잘못 짚으면 게임이 깨지므로 **모든 포인터의 진위를 역추적 검증**했습니다.

- Thumb `LDR Rd,[PC,#imm]` 리터럴 풀 역추적: 585개 확인
- 포인터 배열 소속 판정: 2,159개 확인
- **미확인 21개는 재배치하지 않고 제자리 기록만** 수행 (포인터를 건드리지 않으므로 안전)

## 5. 도구 사용법

전부 Python 3 + Pillow 만 있으면 동작합니다. `numpy`, `capstone` 은 분석 단계에만 쓰입니다.

```bash
pip install pillow
```

각 스크립트 상단의 롬 경로를 자신의 환경에 맞게 수정한 뒤 순서대로 실행하세요.

| 단계 | 스크립트 | 하는 일 |
|---|---|---|
| 1 | `master_extract2.py` | 롬 전체에서 SJIS 문자열 추출 → `master_strings.json` |
| 2 | `build_units2.py` | 포인터 배열로 시퀀스 재구성, 독음 자동변환 분리 → `units2.json` |
| 3 | `build_batches.py` | 번역 배치 + 용어집 생성 |
| 4 | *(번역)* | `TRANSLATE_INSTRUCTIONS.md` 지침에 따라 배치별 번역 |
| 5 | `merge_tr.py` | 배치 결과 병합 → `tr_merged.json` |
| 6 | `validate2.py` | 포맷 코드·금지문자·바이트 제한 기계 검증 |
| 7 | `ptr_confirm.py` | 포인터 진위 역추적 → `unsafe_offsets.json` |
| 8 | `inject.py` | 폰트 글리프 + 번역 텍스트 주입 → 패치 롬 |
| 9 | `verify_all.py` | 전수 재검증 |

보조 도구: `sample_sheet.py`(샘플 이미지), `font_preview.py`(폰트 미리보기),
`verify_final.py`(임의 주소 렌더), `hangul_codec.py`(인코더), `bdf.py`(BDF 파서),
`eumdok.py`(한자 1,624자 독음표)

### 번역만 고치고 싶다면

[`data/번역대조표.txt`](data/번역대조표.txt) 에서 고칠 문장을 찾아
[`data/tr_merged.json`](data/tr_merged.json) 의 해당 항목을 수정한 뒤
`inject.py` 를 다시 돌리면 됩니다. 필요한 한글 글리프는 자동으로 새로 주입됩니다.

## 6. 알려진 제한

- **히라가나 이름 입력 그리드**는 원본 유지 — 한 글자 단위 UI라 한글 조합이 불가능합니다.
- 바이너리 데이터가 문자열로 오인 추출된 조각 **12건**은 원본 바이트를 보존했습니다.
- 인물 열전 등 일부 문장은 전각 폭 제약 때문에 압축된 표현을 썼습니다.
- 고유명사는 일본어 발음이 아닌 **한자 독음**입니다 (직전신장 ≠ 오다 노부나가).
  이 시리즈 한글패치의 관례를 따랐습니다.
